# 💼 Ghufran Shahid – Personal Portfolio

A modern, responsive, and visually engaging personal portfolio website built to showcase my skills, projects, achievements, and professional journey. Designed with a sleek dark theme, smooth animations, and optimized performance, this portfolio serves as my digital identity and highlights my passion for **Web Development, Cybersecurity, Artificial Intelligence, Automation, and Graphic Design**.
